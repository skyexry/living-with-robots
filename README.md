# Living with Robots

A group project for Assignment 1 in **Emerging Technologies & Computational Arts**.

**Project team:** Skye Xi, Sienna Ni, and Wenhao Su.

[Open the interactive magazine](https://skyexry.github.io/living-with-robots/) · [Read the full chapter (PDF)](Living-with-Robots.pdf)

The tour explores how robots shape what people can do, who gets to participate, and who has authority. It features 34 stops with excerpts, case studies, and references from the magazine.

## Explore the tour

Select **Enter the chapter** to begin. Click a highlighted area of the magazine to jump to a case study, or select a citation to view its source.

| Key | Action |
| --- | --- |
| Left / Right arrows | Previous / next stop |
| Space | Next stop |
| O | Open the chapter index |
| E | Explore a spread. Drag to pan, scroll to zoom, and double-click to reset. |
| N | Toggle presenter notes and suggested timing |
| F | Toggle fullscreen |
| Home | Return to the opening |
| Esc | Close panels or exit explore mode |

To browse offline, download the repository and open `index.html` in a browser. The full chapter PDF includes the references and image credits.
